# Data Refinery Simulator

A Spring Boot based telecom data simulator developed as part of my internship project.

## Features

- Generate realistic CDR records
- Generate realistic NAT records
- Configurable through application.yml
- Spring Boot Configuration Properties
- Constructor Dependency Injection
- Modular generator architecture

## Technologies

- Java 21
- Spring Boot
- Maven

## Current Progress

- Generate realistic CDR records
- Generate realistic NAT records
- External configuration using application.yml
- Configurable record count, timestamp and simulation duration
- TCP client support
- Runtime statistics (Generated / Sent / Failed)

## Planned Features

- UDP client
- Runtime -D properties
- File output
- Enhanced logging
